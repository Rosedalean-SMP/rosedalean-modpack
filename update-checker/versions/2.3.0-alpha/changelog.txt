### Changed

- Added FTB Quests chapters and reward tables for Create, Create Crafts & Additions, Exposure, the Let's Do mods, Sophisticated Backpacks and Storage, the Nether, and the End.
- Added client defaults for BCLib, Iris, MidnightLib, Sodium Extra, and Sodium. Iris selects Solas but leaves shaders disabled. Added Modpack Update Checker, PreLoader, and Simple Discord RPC client configs.
- Added server configs for Essential Commands, BlueMap, ChunkyBorder, Hats, ServerCore, Styled Chat, TAB, and Simple Voice Chat. BlueMap has Overworld and Nether maps; its End map config is disabled.
- Added configs for ClickVillagers, Better Compatibility Checker, and Create.
- Enabled ModernFix mixins for dynamic resources, mapping and class-info cleanup, spawn-chunk removal, and Unihex font disabling. Set Naturalist to remove butterflies.
- Added KubeJS recipes for coarse dirt, dough, gunpowder, farmables, horse equipment, dyes, name tags, quartz blocks, and shulker shells. Added Create and Sophisticated Storage recipe integrations. Create now mixes 2 dirt and 2 gravel into 4 coarse dirt, then crushes coarse dirt into dirt.
- Replaced the Create quartz and calcite recipe mod, the BetterEnd and BetterNether compatibility mod, and Ultimate Factory with KubeJS recipes.
- Added Create recipe integrations for dough, gunpowder, and more farmables.
- Removed the old standalone gunpowder and diamond recipe removal scripts.
